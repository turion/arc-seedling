# Changelog

**`SEEDLING.md` is at version 1.** The number lives here and nowhere else — the file does not state
its own — so a bump touches one line instead of two that can disagree.

**Every closed meta-arc produces a new revision of `SEEDLING.md`**, so that someone who has already
adopted an earlier revision can update their own setup **from the diff** rather than re-reading
several thousand lines to find what moved. A revision that changes nothing an adopter must act on
still gets an entry saying so. `AGENTS.md` holds the form a new entry takes.

Newest first.

- **v1** — 2026-10-06 — the first extraction: this system distilled out of a 6,589-line working
  corpus that had accreted on one machine, generalised off that machine, and reorganised into the
  Core / Standard / Optional layering. Still being finished in place, so it carries what the
  originating system grew after the first draft — the pre-challenge gate, the index's summary
  bullets, the challenge phase's empirical exit and `OBJECTIVES.md` — as part of this baseline
  rather than as a revision against it.
  **To update from v0:** there is no v0. v1 is the baseline every later entry is a diff against.
